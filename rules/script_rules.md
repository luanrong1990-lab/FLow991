# SCRIPT RULES (BẮT BUỘC)
- Tiếng Nhật 100%, desu/masu, điềm tĩnh; CẤM giọng hô hào quá mức.
- Cấu trúc đúng thứ tự:
  1) HOOK 30–40s: nêu nỗi đau + hứa hẹn danh sách + teaser một mục ("X 番目は…").
  2) OPENING 20–40s: giới thiệu kênh + disclaimer cố định:
     「この動画は情報整理と紹介が目的で、投資勧誘や利益の保証ではありません。成果は地域と運営次第で変わります。」
  3) N mục ITEM (mặc định 12), mỗi mục 60–90s phủ đủ: は gì → vì sao có lãi → vốn 目安 →
     rủi ro/rào cản → tính lặp lại.
  4) MIDCHECK ~20s: tóm nửa đầu + nhắc lại teaser để giữ chân người xem.
  5) RECAP 60–80s: bảng so sánh + 3 điểm chung.
  6) OUTRO 30–45s: CTA đăng ký + high rating, teaser video kế, nhắc disclaimer.
- Số liệu phải hedge: "目安／一般的に／〜ことが多い". CẤM cam kết lợi nhuận (必ず儲かる…).
- Mỗi scene đủ: visual (mô tả minh họa), narration, telop (mỗi dòng ≤13 ký tự, ≤2 dòng).
- Đánh dấu insert_slot:true nơi nên chèn case study/biểu đồ.
- Tốc độ narration chuẩn 320 ký tự/phút.
